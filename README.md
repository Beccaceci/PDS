# PDS (Programmazione di Sistema)

This repository includes useful materials, such as exam resolutions, study guides, and lab guides, for the course **Programmazione di Sistema** attended at Politecnico di Torino.

## Repository Structure

The repository is divided into two main sections:

### 1. OS INTERNALS
This section covers the internal workings of operating systems.
- **EXAMS**: Past exam papers along with their resolutions, organized by academic year.
- **LABS**: Lab guides and resources. For example, the `study_guide` folder contains the primary `OS161_LABS.pdf` guide.
- **BOOKS**: Reference materials and textbooks related to OS fundamentals.

### 2. API PROGRAMMING
This section focuses on system programming APIs, heavily utilizing **Rust**.
- **EXAMS**: Past exam papers, organized by calendar year (e.g., `2022`, `2023`, `2024`, `2025`). Each exam session (e.g., `exam_2022-07-08`) is structured as a standalone Rust **Cargo project** containing the implemented code solutions for the practical exercises (e.g., concurrency patterns, bounded buffers, dispatchers).
- **STUDY_GUIDE**: Comprehensive study guide for the API programming section, covering Rust fundamentals, memory layout, ownership, iterators, and concurrency.
- **LABS**: Lab materials and exercises for practical API programming.
- **LECTURE TRANSCRIPTIONS & SLIDES**: Course theory and lesson notes.
